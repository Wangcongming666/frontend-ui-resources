# 配色与视觉素材

来源：用户提供的 resources.md。以下为获取入口；除已注明的核验记录外，费用、授权及可下载格式均在实际选中资源时确认。先确定页面用途、风格和所需格式，再找具体素材，不批量抓取整个站点。

## 配色与渐变

| 资源 | 用途 | 使用方式 |
|---|---|---|
| [Coolors](https://coolors.co/) | 生成与探索调色板 | 确定主色、中性色及语义色，再在真实 UI 中检查对比度 |
| [Realtime Colors](https://www.realtimecolors.com/) | 预览配色在界面中的表现 | 观察文本、背景、强调色与按钮组合 |
| [uiGradients](https://uigradients.com/) | 渐变参考 | 需要渐变时选色，不把渐变当作所有页面的默认装饰 |

## 插画

| 资源 | 适合位置 / 内容 | 使用条件 |
|---|---|---|
| [unDraw](https://undraw.co/) | 空状态、引导、概念说明；可调色插画 | 本次许可支持项目中免费商用且无需署名；自有许可，细节见下方 |
| [Storyset](https://storyset.com/) | 场景插画、可改色及分层动效 | 本次条款显示免费使用需署名；无署名使用需符合付费条件 |
| [Blush](https://blush.design/) | 定制人物与品牌插画组合 | 按具体插画包、导出格式和计划核验许可 |

## 字体

| 资源 | 用途 | 接入方式 |
|---|---|---|
| [Google Fonts](https://fonts.google.com/) | 字体、字重及语言覆盖 | 查看具体字体许可证与中文覆盖；按部署环境验证访问 |
| [Fontsource](https://fontsource.org/) | 字体包与自托管 | 按语言、字重、子集选择，避免无关包体积 |

原清单中的 `fonts.loli.net` 未作为默认入口保留：没有核验当前服务、内容一致性与访问表现。需要国内可用字体时优先验证自托管方案，不保证任何域名始终可访问。

## 背景视频

| 资源 | 用途 / 筛选方向 | 授权与获取提示 |
|---|---|---|
| [Pexels Video](https://www.pexels.com/videos/) | 通用背景、生活与品牌氛围 | 取具体视频详情与当前许可 |
| [Pixabay Video](https://pixabay.com/videos/) | 多类型视频 | 检查单项资源条件与画面内容 |
| [Mixkit](https://mixkit.co/free-stock-video/) | 短片与背景素材 | 同站可能适用不同许可，不统一标成免费商用 |
| [Coverr](https://coverr.co/) | 网页背景视频 | 检查具体文件、下载条件与当前计划 |
| [Mazwai](https://mazwai.com/) | 电影感、风景与氛围 | 原文的 CC BY 3.0 不作为全站结论，按单条素材核验 |
| [Dareful](https://www.dareful.com/) | 高分辨率风景与航拍候选 | 原文的 CC BY 4.0 待具体条目确认；明确署名要求 |
| [Videvo](https://www.videvo.net/) | 视频素材候选 | 混合内容与访问状态需核验，按素材判断费用与署名 |

实际接入时给出格式、比例、用途及来源。背景视频考虑短循环、静音、poster、移动端体积与减少动态效果的替代图。不要把图库页面地址当成图片或视频文件 URL。

## 已核验条款（2026-11-14）

- [unDraw 许可](https://undraw.co/license)：允许项目中免费商用且无需署名，但包含图库式再分发、自动化访问和 AI/ML 用途限制。适合推荐项目素材，不据此批量抓取或建立素材聚合服务。
- [Storyset 条款第 6 节](https://storyset.com/terms)：免费授权带有署名条件，无署名使用需满足指定订阅条件。要求“免费且无需署名”时，不把其免费方案列为符合项。

“可商用”不自动覆盖画面里的商标、人物或其他第三方权利；仅在具体素材与用途涉及这些条件时说明，引用对应素材页或许可页。
